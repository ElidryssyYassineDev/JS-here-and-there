# Stopwatch Program

A simple and polished JavaScript stopwatch application built for learning and practice.

## What’s Included

- **`index.html`** — the user interface for the stopwatch.
- **`index.js`** — the stopwatch logic, including start, stop, reset, and lap functionality.
- **`style.css`** — styling for the layout, buttons, and timer display.

## Features

- Start, pause, and reset the stopwatch.
- Clean digital timer display with minutes, seconds, and milliseconds.
- Responsive layout for a smooth experience on desktop and mobile.

## How to Use

1. Open `index.html` in a browser.
2. Click **Start** to begin timing.
3. Click **Stop** to pause the timer.
4. Click **Reset** to return the timer to `00:00:00`.

## Purpose

This folder demonstrates a small JavaScript project focused on DOM interaction, event handling, and basic animation timing. It’s a great example of how to build a functional UI with clean structure and readable code.

## Notes

- Designed as a beginner-friendly project.
- Ideal for learning how timers and UI controls work together in a web app.
- Can be extended with lap tracking, split timing, or sound alerts.
