# Calculator Program

A clean and simple web-based calculator built with HTML, CSS, and JavaScript.

## Features

- Basic arithmetic operations: addition, subtraction, multiplication, and division
- Keyboard-friendly button layout for quick input
- Clear display for current expression and results
- Responsive styling for a modern look

## Files Included

- `index.html` — the app structure and calculator layout
- `style.css` — styling for buttons, display, and overall page design
- `index.js` — calculator behavior, input handling, and calculations

## How to Use

1. Open `index.html` in your browser.
2. Click the calculator buttons or type numbers and operations.
3. Press `=` to get the result.
4. Use `C` (clear) to reset the current expression.

## Purpose

This project demonstrates a basic interactive calculator using plain JavaScript and vanilla web technologies. It is a great example for learning DOM manipulation, event handling, and simple app design.

## Notes

- The calculator is intended for simple arithmetic only.
- Always make sure expressions are valid before pressing `=`.

Enjoy exploring the Calculator Program!
